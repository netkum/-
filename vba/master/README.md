# 팀장 Master – VBA 코드

계획안 v2의 **팀장 통합 파일(`연구팀_Master.xlsm`)**을 구현한 코드입니다.
팀원 파일(`vba/member`)의 데이터를 읽기 전용으로 모아서 대시보드, 프로젝트별 일정, 팀 일정을 만듭니다.
또 `Master\ProjectList.xlsx`를 배포해 프로젝트, 단계, 코멘트, 보고일정을 팀원에게 전달합니다.

사용자 정의 폼이 없습니다. 모듈을 가져온 뒤 **`SetupMaster`를 한 번 실행**하면 설치가 끝납니다.

## 파일

| 파일 | 내용 |
|------|------|
| `modConfig.bas` | 상수(시트·표·열 번호), 설정, 공통 유틸 (팀원 템플릿과 같은 규칙) |
| `modSync.bas` | **[전체 동기화]**: 팀원 파일 수집, 실패 시 이전 데이터 유지, 신규·수정·삭제 비교, 요청 수집, 참여자·자동 PM, PM 단계 반영, 단계 합치기 반영, 결과창 |
| `modCalc.bas` | 진척률 계산 (Task·단계·프로젝트·전체, 작업일수 가중), 계획진척, 지연, 현재 단계, 신호 |
| `modAdmin.bas` | **[요청 처리 적용]**(승인·기존 통합·반려), 팀장 코멘트, **[ProjectList 배포]**, 보고일정 펼치기, 드롭다운 목록 |
| `modDashboard.bas` | Dashboard 화면 |
| `modProjectView.bas` | ProjectView 화면: 단계 현황표와 주 단위 Gantt |
| `modTeamSchedule.bas` | TeamSchedule 화면: 팀원 × 날짜 월간 일정 |
| `modSetup.bas` | **`SetupMaster`**: 시트·표·버튼 자동 구성 |
| `modEvents.bas`, `ThisWorkbook.txt` | 이벤트 연결 |

## 설치 순서 (약 5분)

1. 엑셀에서 새 통합 문서를 열고 `Alt + F11`을 누릅니다.
2. `파일 → 파일 가져오기`로 **`import/` 폴더의 `.bas` 9개**를 가져옵니다. (`src/` 폴더 파일을 가져오면 한글이 깨집니다)
3. `현재_통합_문서`(ThisWorkbook)에 `import/ThisWorkbook.txt` 내용을 붙여넣습니다.
4. `디버그 → VBAProject 컴파일`로 오류가 없는지 확인합니다.
5. `Alt + F8` → **`SetupMaster`** → 실행합니다.
6. 공유폴더의 **`Master\` 폴더**에 `연구팀_Master.xlsm`으로 저장합니다.
   ```
   \\회사서버\...\업무관리\
    ├─ Master\연구팀_Master.xlsm      ← 이 파일
    ├─ Master\ProjectList.xlsx        ← [ProjectList 배포]가 자동 생성 (팀원 파일이 읽음)
    └─ Member\*_업무일정.xlsm          ← 팀원 파일 (자동 검색)
   ```
7. `Setting` 시트를 확인합니다.
   - `MemberFolder`: 비우면 이 파일 폴더의 상위 폴더 아래 `Member`를 사용합니다.
   - `tblTeamEvent`: 팀 공통 보고일정 (예: 주간회의 매주 월 10:00)
   - `tblHoliday`: 공휴일. 대체공휴일은 직접 추가합니다.
8. `ProjectMaster` 시트에 프로젝트를 등록하고 **[ProjectList 배포]**를 누릅니다.

## 시트

| 시트 | 내용 |
|------|------|
| `Dashboard` | • KPI 8개: 전체·진행·완료·지연·금주 마감·미갱신 팀원·프로젝트 요청·PM 지정 필요<br>• 팀 전체 진척 (계획 대비)<br>• 프로젝트별 진척: PM, 현재 단계, 단계 표시 ■◐□▲, 계획·실적·차이, 신호<br>• 담당자별 업무량<br>• 지연 업무 (**M열 노란 칸에 코멘트 입력**)<br>• 이번 주 마감, 승인대기 요청 |
| `ProjectView` | 프로젝트 선택 → 요약, 단계 현황표(기간·담당·진척·계획·상태), 단계 → Task(담당자) 주 단위 Gantt, 오늘선, ◆ 마일스톤 |
| `TeamSchedule` | 월 선택 → 팀원별 일자별 프로젝트 코드와 휴가(회색), 보고일정 ◆, 부재 인원 |
| `TaskAll` | 전체 Task 통합 표. Q열 `팀장코멘트`에 입력 가능. 지연 행은 빨간 글씨 |
| `ProjectMaster` | 프로젝트(PM 지정, 색), 단계, **승인대기 요청**, 코드 변경 기록, 코멘트 목록 |
| `Setting` | 폴더 설정, 팀원 파일 상태, 보고일정, 공휴일, 동기화 기록 |

## 팀장이 하는 일

| 상황 | 방법 |
|------|------|
| 주간 현황 보기 | **[전체 동기화]** 한 번 → Dashboard |
| 프로젝트 자세히 보기 | Dashboard에서 프로젝트 행 더블클릭, 또는 ProjectView 드롭다운 |
| 새 프로젝트 등록 | ProjectMaster `tblProject`에 한 줄 추가 → [ProjectList 배포] |
| 팀원의 프로젝트 요청 처리 | ProjectMaster 승인대기 표의 `처리▼`에서 승인 / 기존 통합 / 반려 선택 → **[요청 처리 적용]** (승인 시 정식코드를 비우면 P### 자동 발급) |
| PM 지정 (참여자 2명 이상) | Dashboard에 `▲ 지정 필요`가 보이면 ProjectMaster `PM(지정)` 드롭다운에서 선택 → [ProjectList 배포] |
| 단계 수정 | 보통은 PM이 팀원 파일에서 합니다. 팀장이 `tblPhase`를 직접 고치면 **팀장 수정이 우선**합니다 (수정일시 자동 기록) |
| 팀원에게 코멘트 | Dashboard 지연 업무 M열 또는 TaskAll Q열에 입력 → 파일을 저장하면 자동 배포 (또는 [ProjectList 배포]) |
| 프로젝트 색 바꾸기 | ProjectMaster `Color` 칸에 채우기 색을 칠함 → 팀원 캘린더에도 같은 색 |

## 동작 규칙

- **수집**
  - Member 폴더에서 `*_업무일정.xlsm` 파일을 찾습니다. 파일명의 `_` 앞부분을 담당자 이름으로 씁니다.
  - 파일은 읽기 전용으로 열었다가 바로 닫습니다. 팀원이 파일을 열어 두어도 **마지막으로 저장된 내용**이 수집됩니다.
- **실패 처리**: 읽지 못한 파일은 해당 팀원의 이전 데이터를 그대로 둡니다. 결과창, Dashboard, `tblSyncLog`에 기록합니다.
- **PM**
  - 팀장이 PM을 지정했으면 그 사람이 PM입니다.
  - 지정하지 않았고 참여자가 1명이면 그 사람이 자동으로 PM입니다.
  - 참여자가 2명 이상인데 지정하지 않았으면 `▲ 지정 필요`로 표시합니다.
  - 요청을 승인해서 만든 프로젝트는 요청자가 PM이 됩니다.
- **단계**
  - PM 본인 파일의 `tblMyPhase`만 반영합니다. 다른 참여자가 가진 단계 표는 무시합니다.
  - Master와 PM 파일 중 수정일시가 더 최신인 쪽을 사용합니다.
- **진척**
  - 진척률은 Σ(작업일수 × 진척률) ÷ Σ(작업일수)로 계산합니다. 휴가·출장·교육·공통 업무와 취소된 Task는 빠집니다.
  - 신호 기준 (실적 − 계획)
    - 완료: 실적 100%
    - 지연: 차이가 −20%p 미만이거나 종료일이 지남
    - 주의: 차이가 −10%p 미만이거나 지연 Task가 있음
    - 정상: 그 외
- **ProjectList.xlsx**: 동기화, 요청 처리, 배포 버튼, 코멘트 변경 후 저장할 때마다 새로 만듭니다. 시트 규격은 `vba/member/README.md`를 참고하세요.

## 알려진 제약 / 확인 필요

- Excel이 없는 환경에서 작성해서 **실제 엑셀로 실행해 보지는 않았습니다.** 구조 검사(블록 짝, 호출 대상 존재, 공개 이름 중복)만 통과했습니다. 설치 후 `디버그 → 컴파일`과 파일럿 테스트가 필요합니다.
- 팀원 파일이 많으면 동기화 시간은 파일 수에 비례해 늘어납니다. 파일을 하나씩 엽니다.
- 보고일정은 오늘 기준 −60일 ~ +180일만 펼쳐서 배포합니다.
- 계획안 2~3단계 기능은 아직 넣지 않았습니다: 진척 추이 스냅샷, PMView, 회의자료 자동 생성.
