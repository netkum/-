# 엑셀 VBA 팀 스케줄러 구축 계획안

> 목적: 사내 보안 환경(외부 AI·클라우드·외부 프로그램 접근 불가)에서 **엑셀 + VBA만으로**
> 팀원 개인 일정 관리 → 프로젝트/Task 단위 관리 → 팀장 통합 현황(프로젝트별 일정·진척도·전체 요약)까지 구현한다.

---

## 1. 목표와 설계 원칙

### 1.1 목표
| # | 목표 | 사용자 |
|---|------|--------|
| 1 | 지금 쓰는 **캘린더 형식 일정표를 거의 그대로 유지**하면서 쓴다 | 팀원 |
| 2 | 팀원마다 **개인 엑셀 파일**을 따로 쓴다 (서로 파일을 건드리지 않음) | 팀원 |
| 3 | 개인 파일 안에서 **프로젝트별 Task를 나눠서** 일정·진척을 관리한다 | 팀원 |
| 4 | 팀원 파일들을 근거로 **프로젝트별 일정을 한눈에** 본다 (간트/팀 캘린더) | 팀장 |
| 5 | **프로젝트별 진척도**와 **전체 업무 요약 진척도**를 본다 | 팀장 |
| 6 | 지연·마감 임박 업무를 **놓치지 않게** 자동으로 걸러준다 | 팀장 |

### 1.2 설계 원칙
1. **외부 연결 0**: 인터넷, 외부 DLL, 애드인, 클라우드 사용 안 함. 엑셀 기본 기능 + VBA + (선택) 사내 Outlook만 사용.
2. **팀원은 입력만, 계산은 팀장 파일에서**: 팀원 파일은 가볍고 단순하게. 집계·분석 로직은 팀장 파일에 집중.
3. **원본 데이터는 한 곳(Task 표)**: 캘린더는 Task 표를 보기 좋게 "그려주는 화면"이다. (이중 입력 방지)
4. **파일 1개 = 작성자 1명**: 공유폴더에서 동시 편집 충돌이 원천적으로 생기지 않게 한다. 팀장은 **읽기 전용**으로만 가져온다.
5. **VBA가 없어도 데이터는 읽힌다**: 모든 데이터는 일반 엑셀 표(ListObject)에 저장 → 매크로가 막혀도 표 자체는 볼 수 있음.

```
 ├─ 02_팀장\

```

## 3. 팀원 개인 파일 (`일정_이름.xlsm`) 상세 설계

### 3.1 시트 구성
| 시트명 | 역할 | 비고 |
|--------|------|------|
| `캘린더` | **기존 캘린더 양식 그대로** + Task 자동 표시 | 팀원이 주로 보는 화면 |
| `Task목록` | 프로젝트별 Task 입력 표 (원본 데이터) | 핵심 |
| `프로젝트별보기` | 내 Task를 프로젝트별로 묶어 보는 요약 + 미니 간트 | 수식/피벗, 선택 |
| `설정` | 이름, 사번(ID 접두어), 공유폴더 경로, 프로젝트 목록 캐시, 공휴일 | 숨김/보호 |

### 3.2 `Task목록` 표 (표 이름: `tblTask`)
| 열 | 항목 | 입력 방식 | 설명 |
|----|------|-----------|------|
| A | TaskID | 자동 | `HGD-0001` 형식 (이니셜-일련번호). 행 추가 시 VBA가 부여, 수정 불가 |
| B | 구분 | 드롭다운 | `프로젝트업무 / 일반업무 / 회의 / 휴가 / 출장 / 교육` |
| C | 프로젝트코드 | 드롭다운 | 프로젝트마스터에서 가져온 목록 (예: `PJ-A01`). 일반업무는 `공통` |
| D | 프로젝트명 | 자동 | 코드로 조회 (XLOOKUP/VLOOKUP) |
| E | 단계 | 드롭다운(선택) | `기획 / 설계 / 개발 / 검증 / 보고` 등 팀 표준 단계 |
| F | Task명 | 직접 입력 | 캘린더에 표시될 문구 |
| G | 시작일 | 날짜 | 필수 |
| H | 종료일(계획) | 날짜 | 필수, 시작일 이후 |
| I | 진척률(%) | 드롭다운 | `0, 10, 25, 50, 75, 90, 100` (자유 입력보다 일관성↑) |
| J | 상태 | 드롭다운 | `예정 / 진행 / 보류 / 완료 / 취소` |
| K | 실제완료일 | 날짜 | 상태=완료 시 VBA가 오늘 날짜 자동 입력(수정 가능) |
| L | 가중치 | 숫자(선택) | 비워두면 **작업일수**를 가중치로 사용 |
| M | 우선순위 | 드롭다운 | `상 / 중 / 하` |
| N | 이슈/메모 | 직접 입력 | 지연 사유, 요청사항 → 팀장 이슈 리스트에 그대로 노출 |
| O | 최종수정일시 | 자동 | 행이 바뀌면 VBA가 기록 (팀장이 "업데이트 안 한 사람" 확인용) |

**입력 규칙(데이터 유효성 + VBA 검증)**
- 종료일 < 시작일 → 입력 거부 + 메시지
- 상태=완료 ↔ 진척률=100 자동 동기화
- 진척률>0 인데 상태=예정 → 상태를 `진행`으로 자동 변경
- 필수값(프로젝트코드, Task명, 시작일, 종료일) 누락 행은 빨간 배경 표시

### 3.3 `캘린더` 시트 – 기존 양식 유지 전략
기존 캘린더 양식을 **그대로 복사해 넣고**, VBA는 "날짜 칸이 어디 있는지"만 알면 되도록 설계한다.

- `설정` 시트에 **레이아웃 정보**만 등록
  - `연도/월 셀 위치` (예: `B2`, `D2`)
  - `첫 날짜칸 위치` (예: `B5`), `날짜칸 1개 높이(행 수)` (예: 날짜 1줄 + 내용 5줄 = 6), `요일 열 수 = 7`
  - 형식 유형: `월간달력형(요일×주)` 또는 `가로날짜형(행=사람/항목, 열=날짜)` — 현재 쓰는 양식에 맞춰 하나 선택
- 날짜칸 내부를 두 영역으로 분리
  - **자동영역**(위쪽 n줄): VBA가 Task를 `[PJ-A01] 설계검토 50%` 형태로 채움, 프로젝트 색상으로 글자/배경 표시
  - **메모영역**(아래쪽 1~2줄): 팀원이 자유롭게 쓰는 칸 → VBA가 절대 지우지 않음 (기존 사용 습관 유지)
- 휴가·출장은 날짜칸 전체를 연한 회색/노랑으로 칠함
- 오늘 날짜 테두리 강조, 주말·공휴일 색상 구분
- 버튼: `◀ 이전달` `다음달 ▶` `캘린더 새로고침` `Task 추가`
- **(편의) 캘린더에서 날짜칸 더블클릭 → Task 입력 폼(UserForm)** 이 뜨고 시작일에 그 날짜가 미리 채워짐 → 저장하면 `tblTask`에 행 추가 후 캘린더 다시 그림
- 칸이 넘칠 때: 자동영역 줄 수를 넘으면 마지막 줄에 `외 2건` 표시 (셀 메모에 전체 목록)

### 3.4 `프로젝트별보기` 시트 (팀원 본인용)
- 프로젝트코드별 Task 수 / 완료 수 / 가중 진척률 (SUMPRODUCT 수식)
- 선택한 프로젝트의 Task 미니 간트 (조건부 서식으로 날짜 열 칠하기 → VBA 없이도 동작)

### 3.5 팀원 파일 VBA 모듈 구성
| 모듈 | 주요 프로시저 | 기능 |
|------|---------------|------|
| `modConfig` | `GetSetting(key)`, 상수 정의 | 설정 시트 값 읽기, 표/시트 이름 상수 |
| `modTask` | `AddTask()`, `NewTaskID()`, `ValidateRow(row)`, `SyncStatus(row)` | Task 추가·ID 부여·검증·상태 동기화 |
| `modCalendar` | `RenderCalendar(y, m)`, `ClearAutoArea()`, `PaintDay(date, items)`, `MoveMonth(±1)` | 캘린더 그리기 |
| `modMaster` | `RefreshProjectList()` | 공통 폴더의 프로젝트마스터를 읽어 드롭다운 목록 갱신 |
| `frmTask` (UserForm) | 입력 폼 | 콤보박스(프로젝트/구분/상태), 날짜 입력, 저장 |
| `Sheet_Task` 이벤트 | `Worksheet_Change` | 최종수정일시 기록, 검증, 상태 동기화 |
| `Sheet_Calendar` 이벤트 | `Worksheet_BeforeDoubleClick` | 날짜칸 → 입력 폼 |
| `ThisWorkbook` | `Workbook_Open` | 이번 달 캘린더 자동 표시, 프로젝트 목록 갱신 시도 |

## 4. 팀장 통합 파일 (`팀_통합대시보드.xlsm`) 상세 설계

### 4.1 시트 구성
| 순서 | 시트명 | 역할 |
|------|--------|------|
| 1 | `대시보드` | 전체 요약 진척도, 프로젝트별 진척 표·그래프, 경고 카운트 |
| 2 | `프로젝트간트` | 프로젝트 → Task → 담당자 단위 간트 차트 (주/일 단위) |
| 3 | `팀캘린더` | 팀원(행) × 날짜(열) 월간 캘린더: 누가 언제 무엇을/휴가 |
| 4 | `지연·이슈` | 지연, 마감 임박(D-3), 장기 미갱신, 이슈 메모 있는 Task 목록 |
| 5 | `팀원부하` | 팀원 × 주차별 동시 진행 Task 수 / 계획 작업일 (히트맵) |
| 6 | `진척추이` | 주간 스냅샷 기반 프로젝트별 진척 추이 그래프 |
| 7 | `프로젝트마스터` | 프로젝트 코드·명·PM·시작/종료·가중치·색상·상태 (→ 공통 폴더로 내보내기) |
| 8 | `팀원설정` | 팀원 이름·파일 경로·사용여부 |
| 9 | `통합데이터` | 수집된 전체 Task 원본 (`tblAll`) + 계산 열 |
| 10 | `스냅샷` | 주차별 진척 기록 누적 (`tblSnap`) |
| 11 | `수집로그` | 수집 일시, 파일별 성공/실패, 건수, 오류 메시지 |

### 4.2 `프로젝트마스터` (표 이름: `tblProject`)
| 항목 | 예시 | 설명 |
|------|------|------|
| 프로젝트코드 | `PJ-A01` | 고유키, 팀원 드롭다운의 근거 |
| 프로젝트명 | `A사 설비 개선` | |
| PM/책임자 | 홍길동 | |
| 시작일 / 종료일(목표) | 2026-09-01 / 2026-12-15 | 간트 표시 범위, 계획진척 기준 |
| 프로젝트 가중치 | 3 | 전체 요약 진척 계산 시 사용 (1~5, 미입력 시 Task 작업일 합) |
| 표시색상 | 셀 배경색 | 팀원 캘린더·간트 공통 색상 |
| 상태 | `진행 / 완료 / 보류` | 완료·보류는 대시보드 기본 필터에서 제외 |

`프로젝트마스터 배포` 버튼 → `00_공통\프로젝트마스터.xlsx`로 저장 → 팀원 파일이 열릴 때 자동 반영.

### 4.3 `팀원설정` (표 이름: `tblMember`)
| 이름 | 파일경로 | 이니셜 | 사용 | 마지막수집 | 결과 |
|------|----------|--------|------|------------|------|
| 홍길동 | `\\팀공유\팀스케줄러\01_팀원\일정_홍길동.xlsm` | HGD | Y | (자동) | (자동) |

- `폴더 스캔` 버튼: `01_팀원` 폴더의 `일정_*.xlsm`을 자동으로 목록에 추가

### 4.4 `통합데이터` (표 이름: `tblAll`)
팀원 `tblTask`의 전 열 + 아래 **수집 시 추가/계산 열**
| 계산 열 | 산식 |
|---------|------|
| 담당자 | 파일의 설정 시트 이름 |
| 수집일시 | Now |
| 작업일수 | `NETWORKDAYS(시작일, 종료일, 공휴일)` |
| 가중치(적용) | 입력 가중치 없으면 작업일수 |
| 계획진척률 | 아래 5.1 참조 |
| 차이(실적-계획) | 진척률 − 계획진척률 |
| 신호등 | 정상 / 주의 / 지연 / 완료 (5.3) |
| D-day | 종료일 − 오늘 |
| 미갱신일수 | 오늘 − 최종수정일시 |

### 4.5 수집 방식 (핵심)
**기본안: `Workbooks.Open`(읽기전용) 방식**
- 사내 DRM(문서보안) 적용 파일도 엑셀 자체로는 열리므로 가장 호환성이 높음
- 절차: 화면갱신·이벤트·자동계산 끄기 → 각 파일 ReadOnly로 열기 → `tblTask` 범위를 **배열로 한 번에 읽기** → 닫기(저장 안 함) → 배열을 `tblAll`에 한 번에 쓰기
- 팀원이 파일을 열어놓고 있어도 읽기전용이므로 충돌 없음 (마지막 **저장된** 내용 기준)

**대안: ADO(ACE OLEDB)로 닫힌 파일 조회**
- 파일을 열지 않아 빠름(팀원 10명 이상일 때 유리)
- 단, DRM 암호화 파일은 읽지 못하는 경우가 많음 → `설정`에서 방식 선택 가능하게 하고 실패 시 자동으로 기본안으로 재시도

**오류 처리**
- 파일 없음 / 열기 실패 / 표 없음 / 필수 열 누락 → 해당 팀원만 건너뛰고 `수집로그`에 기록, 대시보드 상단에 "수집 실패 1명" 경고
- 수집 전 기존 `tblAll`을 `스냅샷` 계산이 끝난 후에만 교체 (중간 실패 시 이전 데이터 유지)

### 4.6 화면별 상세

#### ① `대시보드`
- **상단 KPI 카드(셀 병합 + 큰 글꼴)**
  - 전체 요약 진척률(실적) / 전체 계획 진척률 / 차이(%p)
  - 진행중 프로젝트 수, 진행중 Task 수
  - 🔴 지연 Task 수, 🟡 주의 Task 수, ⏰ 이번주 마감 Task 수, 💤 7일 이상 미갱신 팀원 수
  - 마지막 수집 일시 / 수집 실패 수
- **프로젝트별 진척 표**
  | 프로젝트 | PM | 기간 | Task(완료/전체) | 계획% | 실적% | 차이 | 신호등 | 지연Task | 참여인원 | 최종마감 |
  - 실적%는 조건부서식 **데이터 막대**, 신호등은 조건부서식 아이콘/색
  - 프로젝트명 클릭(하이퍼링크) → `프로젝트간트`가 해당 프로젝트로 필터된 상태로 이동
- **그래프**
  - 프로젝트별 계획 vs 실적 가로 막대그래프
  - 전체 진척 도넛(완료/진행/미착수 작업일 비율)
  - 팀원별 담당 Task 수 누적막대(상태별)

#### ② `프로젝트간트`
- 상단 필터: 프로젝트(전체/개별), 담당자, 기간(시작 주~), 단위(일/주)
- 행 구조: **프로젝트 요약행(굵게, 프로젝트 색)** → 그 아래 Task 행(담당자, 진척률)
- 열: 날짜(또는 주차). VBA가 셀 배경으로 막대 그림
  - 계획 기간 = 연한 프로젝트색, 진척 부분(기간 × 진척률) = 진한 프로젝트색
  - 오늘 열 = 빨간 세로 테두리, 주말/공휴일 = 회색
  - 종료일 지났는데 미완료 = 막대 끝 빨간 표시
- 셀 개수가 많아지면 느려지므로 **표시 기간 최대 26주** 제한, 주 단위 모드 제공

#### ③ `팀캘린더`
- 월 선택 → 행: 팀원, 열: 날짜(1~31)
- 셀 값: 그날 진행 중인 Task의 프로젝트코드(여러 개면 `A01, B02`), 휴가/출장은 `휴가` + 색상
- 셀에 마우스 올리면(셀 메모) Task명 목록 표시
- 하단: 일자별 "부재 인원 수" 행 → 일정 조율 시 활용

#### ④ `지연·이슈`
자동 추출 조건 (하나라도 해당하면 목록에 표시, 우선순위 순 정렬)
1. 종료일 < 오늘 이고 미완료 → **지연**
2. 실적 − 계획 ≤ −20%p → **주의**
3. 종료일까지 3영업일 이내 & 진척 < 80% → **마감 임박**
4. 최종수정일시가 7일 이상 경과 & 진행중 → **미갱신**
5. 이슈/메모 열이 비어있지 않음 → **이슈**
- 열: 구분, 프로젝트, Task, 담당자, 종료일, D-day, 계획%, 실적%, 이슈메모, `팀장 조치메모`(팀장 입력, 다음 수집 때도 TaskID 기준으로 유지)

#### ⑤ `팀원부하`
- 행: 팀원, 열: 주차 → 값: 해당 주 진행 Task 수(또는 가중 작업량)
- 색상 스케일(조건부서식): 0~1 초록, 2~3 노랑, 4 이상 빨강 → 업무 재배분 근거

#### ⑥ `진척추이`
- `주간 스냅샷 저장` 버튼(또는 수집 시 매주 월요일 첫 수집 때 자동) → `tblSnap`에 `기준일, 프로젝트, 계획%, 실적%` 누적
- 프로젝트별 계획선 vs 실적선 꺾은선 그래프 → 지연이 "언제부터" 시작됐는지 확인

## 5. 진척도 산정 규칙

### 5.1 Task 단위
- **실적 진척률** = 팀원이 입력한 진척률 (완료=100%, 취소=집계 제외)
- **계획 진척률** (오늘 기준으로 "이만큼은 했어야 함")
  - 오늘 < 시작일 → 0%
  - 오늘 ≥ 종료일 → 100%
  - 그 사이 → `경과 작업일 ÷ 전체 작업일` (NETWORKDAYS, 공휴일 반영)

### 5.2 프로젝트 단위 (가중 평균)
```
프로젝트 실적% = Σ(Task 가중치 × Task 실적%) ÷ Σ(Task 가중치)
프로젝트 계획% = Σ(Task 가중치 × Task 계획%) ÷ Σ(Task 가중치)
Task 가중치 = 입력 가중치, 없으면 작업일수(NETWORKDAYS)
```
→ 1일짜리 Task와 20일짜리 Task가 같은 비중이 되는 왜곡을 방지.

### 5.3 전체 업무 요약
```
전체 실적% = Σ(프로젝트 가중치 × 프로젝트 실적%) ÷ Σ(프로젝트 가중치)
```
- 프로젝트 가중치 미입력 시 해당 프로젝트 Task 가중치 합(=총 작업일) 사용
- 휴가/출장/교육 구분은 진척 계산에서 **제외** (일정 표시만)
- `일반업무`(공통)는 옵션: 포함/제외 선택 (`설정` 시트)

### 5.4 신호등 기준 (설정 시트에서 변경 가능)
| 신호 | 조건 |
|------|------|
| ✅ 완료 | 실적 100% |
| 🟢 정상 | 실적 − 계획 ≥ −10%p |
| 🟡 주의 | −20%p ≤ 차이 < −10%p, 또는 마감 3영업일 이내 & 실적 < 80% |
| 🔴 지연 | 차이 < −20%p, 또는 종료일 경과 & 미완료 |

## 6. 핵심 VBA 코드 골격 (구현 시 출발점)

### 6.1 팀장: 팀원 파일 수집
```vba
' modCollect
Public Sub CollectAll()
    Dim wsM As Worksheet, r As ListRow, allRows As Collection
    Dim data As Variant, okCnt As Long, ngCnt As Long

    SpeedOn
    Set allRows = New Collection
    Set wsM = ThisWorkbook.Worksheets("팀원설정")

    For Each r In wsM.ListObjects("tblMember").ListRows
        If r.Range.Columns(4).Value = "Y" Then
            data = ReadMemberFile(r.Range.Columns(2).Value, r.Range.Columns(1).Value)
            If IsArray(data) Then
                allRows.Add data
                r.Range.Columns(6).Value = "성공 " & UBound(data, 1) & "건"
                okCnt = okCnt + 1
            Else
                r.Range.Columns(6).Value = "실패: " & data   ' data 에 오류 메시지
                ngCnt = ngCnt + 1
            End If
            r.Range.Columns(5).Value = Now
        End If
    Next r

    WriteAllData allRows          ' tblAll 을 한 번에 교체
    WriteLog "수집 완료", okCnt, ngCnt
    SpeedOff
End Sub

Private Function ReadMemberFile(ByVal path As String, ByVal owner As String) As Variant
    Dim wb As Workbook, lo As ListObject
    On Error GoTo EH
    If Dir(path) = "" Then ReadMemberFile = "파일 없음": Exit Function

    Set wb = Workbooks.Open(Filename:=path, ReadOnly:=True, UpdateLinks:=0, AddToMru:=False)
    Set lo = wb.Worksheets("Task목록").ListObjects("tblTask")
    If lo.DataBodyRange Is Nothing Then
        ReadMemberFile = "Task 없음"
    Else
        ReadMemberFile = AppendOwner(lo.DataBodyRange.Value, owner)  ' 담당자 열 추가한 2차원 배열
    End If
    wb.Close SaveChanges:=False
    Exit Function
EH:
    ReadMemberFile = Err.Description
    If Not wb Is Nothing Then wb.Close SaveChanges:=False
End Function
```

### 6.2 계획 진척률
```vba
' modProgress
Public Function PlannedPct(ByVal s As Date, ByVal e As Date, ByVal today As Date, hol As Range) As Double
    Dim total As Long, done As Long
    If today < s Then PlannedPct = 0: Exit Function
    If today >= e Then PlannedPct = 1: Exit Function
    total = Application.WorksheetFunction.NetworkDays(s, e, hol)
    done = Application.WorksheetFunction.NetworkDays(s, today, hol)
    If total <= 0 Then PlannedPct = 1 Else PlannedPct = done / total
End Function
```

### 6.3 팀원: 캘린더 그리기 (월간달력형)
```vba
' modCalendar
Public Sub RenderCalendar(ByVal y As Integer, ByVal m As Integer)
    Dim ws As Worksheet, firstCell As Range, d As Date, lastD As Date
    Dim cellTop As Range, weekIdx As Long, dayIdx As Long
    Dim rowsPerDay As Long, autoLines As Long

    Set ws = Worksheets("캘린더")
    Set firstCell = ws.Range(GetSetting("첫날짜칸"))       ' 예: B5
    rowsPerDay = GetSetting("날짜칸행수")                   ' 예: 6
    autoLines = GetSetting("자동표시줄수")                  ' 예: 4 (나머지는 메모영역)

    ClearAutoArea ws, firstCell, rowsPerDay, autoLines     ' 메모영역은 건드리지 않음
    d = DateSerial(y, m, 1): lastD = DateSerial(y, m + 1, 0)

    Do While d <= lastD
        weekIdx = (Day(d) + Weekday(DateSerial(y, m, 1), vbSunday) - 2) \ 7
        dayIdx = Weekday(d, vbSunday) - 1
        Set cellTop = firstCell.Offset(weekIdx * rowsPerDay, dayIdx)
        cellTop.Value = Day(d)
        PaintDay cellTop, TasksOn(d), autoLines             ' 해당일 진행 Task 표시
        d = d + 1
    Loop
End Sub
```
> 실제 기존 양식의 칸 위치에 맞춰 `설정` 값만 바꾸면 되도록 **좌표를 하드코딩하지 않는다.**

### 운영 규칙 (팀 합의 필요)
1. 매주 **금요일 17시까지** 각자 Task 진척률·상태 갱신 후 저장

| 위험 | 영향 | 대응 |

| 팀원들이 갱신을 안 함 | 대시보드 신뢰도 하락 | `미갱신일수` 표시, 주간 갱신 규칙, 입력 항목 최소화(진척 드롭다운) |
| 보안 정책으로 매크로 차단 | 기능 불가 | 준비단계에서 IT 확인, 신뢰 위치/서명 방식 확보. 최악의 경우 팀원 파일은 매크로 없이 수식만 쓰는 **xlsx 버전**으로도 운영 가능하도록 설계(원칙 5) |
| DRM으로 ADO 조회 불가 | 수집 실패 | 기본값을 `Workbooks.Open` 방식으로 |
| 팀원별 양식 임의 변경 | 수집 오류 | 표 이름·열 이름 기준 조회(열 순서 무관), 표 머리글 시트 보호, 버전 체크 |
| 파일 수 증가로 속도 저하 | 사용 불편 | 배열 처리, 완료 후 3개월 지난 Task는 `보관` 시트로 이동 |
| 기존 양식과 너무 달라 거부감 | 정착 실패 | 캘린더 화면·메모영역을 그대로 두고 "Task 표 한 장만 추가"로 안내 |
